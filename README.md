## 翻译与润色原则

1. **语义优先、整句成译**：以完整语境和整句含义为准，不逐词硬译；对白按口语中译，称呼、语气贴合人物身份与场景；语序可按中文习惯重组，但不改变原意。
2. **多语对照校勘**：以英文为主本，对照官方德文、法文译本反推语义，纠正错译、补回漏译；德法两版也保留原词时，判为品牌 / 控件专名倾向，标注待定留待真机确认。
3. **专有名词分层**：人名、地名、昵称、任务赛道名按系列惯例音译；界面菜单、纯多人独占内容、制作名单、真实人物与品牌名不译；需照抄键入的姓名字段保留英文，关键提示句中英双语。
4. **格式与控制符守恒**：`~n~` `~r~` `~g~` `~b~` `~y~` `~p~` `~s~` `~a~` `~m~` `~z~` 等控制码随原文逐字保留，不改配色、不串位；数字、金额、时间格式照原样；译文长度尽量不超过原文 120%。
5. **术语统一与缺字避让**：同一术语全书一致，分歧以术语表为准；缺字经改译避开，不硬塞未入字表的生僻字。
6. **质量闸**：三章 gxt 条目 0 缺 0 多；独有键核查通过；控制码守恒；回环打包 0 不一致。

## 安装 / 卸载（摘要）

1. 把 zip 解压到**独立文件夹**（不要解压进游戏目录）。
2. Windows 双击 `安装.bat`；SteamOS/Proton 终端跑 `bash install.sh`。
3. 卸载：Windows `卸载.bat`；Linux `bash uninstall.sh`，还原到原版英文状态。
4. 装过其它旧汉化时，先跑清理脚本隔离残留。
