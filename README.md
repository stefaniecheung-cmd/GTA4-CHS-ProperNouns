## 一、来龙去脉

GTA4 官方未提供简体中文。民间简中补丁 `GTA4.CHS.asi` 由**无名汉化组于 2016 年底立项**，2019 年停工后由 **GTA4 贴吧吧友接棒续作三年**完工（2024-09-13 版）。

- **v1.0（"补丁的补丁"）**：在该民间补丁之上，补完其刻意保留英文的人名、地名、车名与整句漏译，字库扩至 3,580 字，并附 `mapfix.asi` 修复暂停地图区名乱码。该版不含原补丁本体，玩家必须先另装 `GTA4.CHS.asi` 才能使用。
- **v2.0（整合包）**：在 v1.0 成果之上做三章译文定稿与字库再扩容，并把主补丁本体一并打包，形成**解压即装**的完整汉化包。
- **v2.1（本版）**：补齐 update 层安装/还原对称文件、更正英文原版回滚基底、新增旧汉化扫描隔离与 SteamOS/Linux 一键脚本；本次修订对主补丁 `GTA4.CHS.asi` 做了 1 处定点闪退修复，并统一补全翻译与润色原则。

## 三、翻译与润色原则

1. **语义优先、整句成译**：以完整语境和整句含义为准，不逐词硬译；对白按口语中译，称呼、语气贴合人物身份与场景；语序可按中文习惯重组，但不改变原意。
2. **多语对照校勘**：以英文为主本，对照官方德文、法文译本反推语义，纠正错译、补回漏译；德法两版也保留原词时，判为品牌 / 控件专名倾向，标注待定留待真机确认。
3. **专有名词分层**：人名、地名、昵称、任务赛道名按系列惯例音译；界面菜单、纯多人独占内容、制作名单、真实人物与品牌名不译；需玩家照抄键入的姓名字段保留英文，关键提示句中英双语。
4. **格式与控制符守恒**：`~n~` `~r~` `~g~` `~b~` `~y~` `~p~` `~s~` `~a~` `~m~` `~z~` 等控制码随原文逐字保留，不改配色、不串位；数字、金额、时间格式照原样；译文长度尽量不超过原文 120%，避免界面溢出。
5. **术语统一与缺字避让**：同一术语全书一致，分歧以术语表为准；缺字经改译避开，不硬塞未入字表的生僻字。
6. **质量闸**：三章 gxt 条目 0 缺 0 多；独有键核查通过；控制码守恒；回环打包 0 不一致。

## 五、安装与卸载

**安装**

1. 把 zip 解压到一个**独立文件夹**（不要解压进游戏目录）。
2. 确认游戏与 Steam 未运行，双击 `安装.bat`；SteamOS/Proton 终端跑 `bash install.sh`；自动定位游戏本体，无需把文件夹放进游戏目录。
3. 看到「全部文件安装成功」后启动游戏。

**卸载**

双击 `卸载.bat`（Linux `bash uninstall.sh`）：还原 update 目录的三章字库图集与译文字典为原版基底，删除主补丁、`GTA4.CHS` 数据文件夹与 `mapfix.asi`，回到原版英文状态。请勿删除包内 `_ORIGINAL_*` 文件。

## 六、已知事项 / 未决边界（如实标注）
