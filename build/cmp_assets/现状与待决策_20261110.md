### 十、whm_table 机制核实（2026-11-10，纠正旧定性）

- **源码依据**：ckeleshi/GTA4.CHS `plugin/whm_table.cpp/.h`、`plugin/gta_whm.cpp`、`plugin/font.cpp`。
- **whm_table.dat 不是字符宽度量表**：它是**游戏内网页（.whm / CHtmlDataNode）整串译文替换表**。`LoadTable` 读 entries(FNV hash, offset) + strings；`GetTranslated(src)` 按 FNV hash 查偏移，命中返回译文串、未命中返回原文；gta_whm hook CHtmlDataNode 虚表函数替换网页自带文本。
- **字宽机制**：font.cpp 中文（非原生字符）统一走 `GetCHSCharacterSizeNormal/Drawing`，固定 `fChsWidth=32.0f`（+ fChsWidthFix=-1 + 字间距 extra_width），**所有汉字同一 advance width，等宽排版**；不存在 per-char 宽度表，新字无需"登记宽度"，也不会回退全角宽，新字与旧字同宽。
- **结论**：44 新字能否渲染由 char_table.dat（白名单）+ fonts.wtd（字模）决定，已入表；whm_table 不登记单字、无需为新字改动，沿用原补丁即可。旧台账/摘要"whm_table=宽度量表、新字未登记会回退全角宽"为定性错误，已在 RELEASE_NOTES.md 与包内使用说明中纠正，离线校验仍 72 OK / 0 FAIL。
- **边界**：若游戏内网页用到新字且该网页串未被 whm_table 替换，网页仍显英文/原生字体，属网页汉化覆盖范围（本包范围仅 GXT，网页 .whm 另行立项），与字宽无关。
