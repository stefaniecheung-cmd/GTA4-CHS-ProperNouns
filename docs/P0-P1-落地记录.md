### 装的时候踩的两个坑（已解决，记下来免得复现）

1. **`--log <path>` 会让 setup.exe 直接以退出码 87 退出**（参数无效，安装器打印用法后关闭）。装 Build Tools 时不要传 `--log`，日志看 `%TEMP%\dd_installer_elevated_*.log`。
2. **必须在前台会话提权**：后台任务里 `Start-Process -Verb RunAs` 拿不到桌面会话，UAC 不会弹、安装器会一直空转。前台调用才会正常弹 UAC。

## 5. P1 骨架实现（已完成）

### 5.1 源码位置

`C:\Game\gta4-chs\src\`

| 文件 | 职责 |
|---|---|
| `dllmain.cpp` | 入口；`DllMain` 只做最小动作，文件 IO/初始化全部丢给工作线程（避免 loader lock 死锁） |
| `log.cpp` / `log.h` | 线程安全日志：`[时间] [级别] [模块] 消息`，UTF-8，8 MB 滚动保留 `.1`，分级过滤 |
| `config.cpp` / `config.h` | 极简 INI 解析（支持 UTF-8 BOM 与 UTF-16LE BOM，键名不区分大小写，行尾 ` ;` 注释剥离） |
| `fingerprint.cpp` / `fingerprint.h` | 版本指纹 = 大小 + FileVersion + SHA1 |
| `build.bat` | 自动定位 vswhere → vcvars32 → 编译到 `..\out\z_gta4cn.asi` |

### 5.2 构建

```powershell
& "C:\Game\gta4-chs\src\build.bat"
```

产物：`gta4-chs\out\z_gta4cn.asi`（179,200 字节，PE x86）。

### 5.3 构建期踩的坑（已解决）

| 现象 | 原因 | 处理 |
|---|---|---|
| 大量 `C2065 未声明的标识符`，中文注释变乱码 | 源码是 UTF-8 无 BOM，MSVC 在 zh-CN 环境按 GBK 解析 | cl 加 `/utf-8` |
| `LNK2019 __imp__CryptAcquireContextW@20` 无法解析 | 本机 SDK 的 `Crypt32.Lib` 里**根本没有** `CryptAcquireContextW` 等导出符号（实测字节搜索 0 命中） | 弃用 CryptoAPI，改为**内置纯 C SHA-1**，零外部依赖 |
| 加载后进程 `0xC00000FD`（栈溢出） | `FileSha1` 里 1 MB 局部缓冲区，工作线程默认栈只有 1 MB | 改静态 64 KB 缓冲 |
