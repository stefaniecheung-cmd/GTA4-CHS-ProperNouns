# P3 语义抽查第二轮：结论与修复记录

日期：2026-11-08

## 一、清单来源与误报判定

`data\review\P3_疑似漏句_过滤.tsv`（312 条）由「英文句数 ≠ 中文句数」筛出，按章节分布：base 179 / TBoGT 93 / TLAD 40。

复核结论：**全部 312 条都不是漏句，属判据误报。**

原因：该判据按句号/问号/感叹号计数，而中英文断句习惯不同——英文口语常把多句合成一句用逗号连接，中文译文按语义合并后句号数量自然减少；另有中文结尾省略句号的情况。两者都会让「句数」对不上，但译文内容完整。

## 二、长度比复筛（换判据）

改用「中文字符数 / 英文单词数」作比值，基准确认：完成翻译的条目该比值通常在 1.0–1.8 之间。

| 区间 | 条数 | 判定 |
|---|---|---|
| 严重偏短（< 0.6） | **0** | 无真漏句 |
| 可疑（0.6–1.0） | 1 | 核对为口语省略（"Okay?" 未译），不影响语义 |
| 正常（≥ 1.0） | 311 | 内容完整 |

**结论：不存在漏句/漏段。**

## 三、人工抽样核对
