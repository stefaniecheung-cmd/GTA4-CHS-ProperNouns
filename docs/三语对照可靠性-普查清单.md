对 E2CM1AU 做序列位移扫描（按大写专名做跨语锚点，k=-12..+12）：

```

k=+6  0.000
k=-5  0.000
```

k=0 显著最优 → **不存在整体位移**。

实证例子：英文被切成两条

```
E: because it's like giving the kids pornography.     ← 德语为空（0E9B0291）

德语把这两句合并成了一句，所以英文这条的德文列是空的，下一条的德文列装的是「因为那等于给孩子看色情」。**这是官方各语种断句习惯不同造成的，不是数据损坏。**

## 六、已被推翻的判据（避免重复试）

- ❌ 用「E 与 D 标点签名不一致」判错位 —— 方向反了。`D=F≠E` 是**表健康**的信号（德法互证一致），不是错位信号。
- ❌ 用「D/F 长度比极端」判错位 —— 三种语言天然长度差大，正常翻译就在 0.9~1.2 波动，阈值抓不到真问题。
- ❌ 用「专名 Jaccard 低」直接判错位 —— 无人名的表（如夜店保安对白 `E2BOAUD`）样本天然为空，0.000 是「无法判定」，不是「错位」。
- ✅ 可靠信号只有两个：**同表内德法成对为空**（切分差异）、**k=0 不是最优位移**（真位移，全库未发现）。

### 追加发现：不只是缺条，还是序列偏移

按 gxt 内条目顺序取相邻上下文，德语并非「把缺的句子并进邻条」，而是**整段错位**：

```
英语序列第 41 条  crc=31DE2983
  [-2] 2F9F51A6  E: Can I ask you something, pal -
                 D: Wenn du sechzig bist,            ← 德文是「当你六十岁」
  [-1] 31C5AACA  E: And I always think, well, what if you're a necrophiliac?
                 D: Beweg dich bloß nicht!           ← 德文是「动都别动」
  [+0] 31DE2983  E: Apparently, now we've got to call them poof lanterns.   ← 缺
```

英语 `Can I ask you something, pal` 的德语位上装的是「当你六十岁」，而「当你六十岁」在英语里是另一条（`4B938AAE` `By the time you're sixty`）。说明**德语序列比英语短 13 条，且排列与英语不同**，不是单纯合并。

### 对中文译文的含义

- `crc` 是键，游戏按 crc 取文；中文只要**对着英语 crc 译**就是对的
- 前提是上游译者确实按英语译，不是按德语译 —— 这一点要在逐条读时验证（若发现某条中文语义明显贴着德文而不贴英文，就是串了）
- **德法在本表不可作同句证人**，只能作整段语境参考
