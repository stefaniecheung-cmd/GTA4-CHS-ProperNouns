生成：2026-11-08　来源：`GTA4 简中补丁之补丁（含AI翻译）v1.0\翻译对照表.md`（1,501 行表格）

## 前言：这份对照表是什么，能用来干什么

它是「无名汉化组原版补丁」之上的一层增补包，专门补**专有名词**：人名 623、区名 74、地名 235、街名/桥名 309、车名 166、联系人/赛道名 94。

**它不是译文来源，是「第二意见」**。原因：

1. 它的人名口径与我们相反：它把 `Niko`→尼克、`Roman`→罗曼，而我们已拍板这两个保留英文，全库改了 2,980 条。
2. 它的部分译法比我们差（`Zombie`→鞭尸者、`Burrito`→屌客、`Sultan`→王者、`Middle Park`→中心公园），不能盲采。
3. 它的剧情整句 1,611 条是 AI 翻译，且不进本表，不能当译文依据。

**但它的区名层与我们几乎完全重合**（74 条里 73 条逐字一致），说明两套译名同源；
而街名 309 条、车名 166 条是我们目前覆盖最薄的一层，正好对上「439 条原则 3 街道地名」那笔未执行的活。

## 五、怎么用（结论）

| 用途 | 结论 |
|---|---|
| 74 区名 | **已无增量**，只 1 条待拍板 |
| 34 条漏译 | **立刻可补**，其中 `Broker.` 占 17 条（HUD/短信区名仍显示英文，是明确缺陷） |
| 38 条冲突 | **当校验清单用**，里面既有我们错的（见下），也有它更差的 |
| 309 街名 + 166 车名 | **当参考词典用**，供 439 条原则 3 与 P4 通读时随手查 |
| 人名 623 | **不用**（与 Niko/Roman 保留英文的口径正面冲突） |

### 这批冲突里，疑似「我们错」的（需优先看）

- `RACES|5D6E9884` `Annihilator`：我们译「灭火器」——**错**，Annihilator 是武装直升机，应为「歼灭者」（我们术语表也写歼灭者）
- `MAIN|170F2C1E` / `E76A3064` `Dukes`：我们「公爵」——术语表定「公爵区」，存量不一致
- `LCPDAE` 系列 `Alderney City, Alderney`：我们「奥尔德尼，奥尔德尼市」——语序反了，应为「奥尔德尼市，奥尔德尼」
- `MAIN|793039BB` / `965215EC` `Police`：我们「警察」——车名语境应为「警车」
- `MAIN|C9E8FF76` `Laundromat`：我们「自助洗衣店」——车名语境应为「洗衣店货车」

### 这批冲突里，它更差、我们不必改的

- `Zombie` 它「鞭尸者」/ 我们「僵尸」；`Burrito` 它「屌客」/ 我们「布里托」
- `Sultan`、`Sultan RS` 它「王者」/ 我们「苏丹」
- `Middle Park` 它「中心公园」/ 我们「中央公园」
- `Stratum` 它「地层先锋」/ 我们「地层」（判例已定）
