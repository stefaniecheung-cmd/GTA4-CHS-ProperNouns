### 2.1 序数后缀碎片（11 条）— **已定：保留原样**

`ND / nd / TH / th / RD / rd / ST / st / ~1~ST / ~1~ND / ~1~TH` 是把英文 "1st/2nd/3rd/4th" 的后缀单独拆出来的键。德文对应 `.`、法文对应 `e`，证明它们只是拼在数字后的序数尾巴。中文序数无法把「第」放到数字后面，译任何内容都会拼错。

**结论（2026-11-08 用户拍板）**：保留英文原样，已从 `defer_list.tsv` 迁入 `keep_en.tsv`。
