## 八、`custom_translations.json` 的作用与归属（已查证）

文件：`plugins\GTA4.CHS\custom_translations.json`（游戏内 3,046 B / A 包原件 280 B），87 组键值。

**机制**：键是 FusionFix 内部硬编码的标识符（`GTAIV.EFLC.FusionFix.asi` 内实测含 `SkipIntro`@0x268B7C、`BorderlessWindowed`@0x268BB4、`FpsLimitPreset`@0x268BC8 等字符串）；值是对应中文名。读取方是 `GTA4.CHS.asi`（其二进制内含 `custom_translations.json` 文件名@0x271BC，自拼路径加载）。

这三个 key 都不在 gxt 里，也不在 `frontend_menus.xml` 里——是 FusionFix 自己的一套 UI 标识符体系。

**与我们的字形层路线的关系：不冲突，互补且分属两层。**

| | GTA4.CHS 路线 | 我方字形层 |
|---|---|---|
| 解决的问题 | 词：英文 → 中文 | 字：把中文画出来 |
| 手段 | 字符串替换 | 字符 → 槽位 → UV 接管 |
| 不解决 | 画不出来 | 词还是英文 |

**结论：**
- **运行时不需要**：宿主 `GTA4.CHS.asi` 已移出游戏目录，该 JSON 现在是死数据，可随 `plugins\GTA4.CHS\` 一并隔离。
- **资产上要单独留档**：87 条是已校对的 FusionFix 术语中文名，是后续「FusionFix 中文化」的直接原料。
- **前提**：它只换词。字形层未通之前，换出来的中文同样显示 `!!!`，因此其优先级排在字形层之后。

## 九、`frontend_menus.xml` 归属说明（避免误覆盖）

Solitude 3 提供的三章 `frontend_menus.xml` 已叠加在 FusionFix 5.1.2 之上，文件比纯 FusionFix 版各大约 200 字节（base 91,886 vs 91,659 / TLAD 112,873 vs 112,666 / TBoGT 104,329 vs 104,122），游戏内实测安装的正是这一版。**任何部署动作都不得用纯 FusionFix 包覆盖这三份 XML**，否则会打掉 Solitude 3 的菜单项与其 5.1.2 适配。
