# 翻译规范（v1，2026-11-08 定稿）

## 一、总原则

能翻译且不影响游戏体验的一律翻译。判据是「玩家在界面上看得到、看得懂更好」——而不是「原文看起来像英文就翻」。

## 二、处理规则

| 类别 | 条目数 | 处理 |
|---|---|---|
| 正文（台词、提示、说明、菜单文案） | 2,062 | 全部翻译 |
| ZiT 电台播报 | 192 | 套模板翻译，歌名/乐队名保留原文 |
| `PLACEHOLDER` 占位串 | 281 | 保留原文（不在界面显示） |
| 纯符号 / 1–2 字符 | 172 | 保留原文 |
| **多人模式名、队名、电台名等官方专有名词** | 分散在上述正文中 | **保留英文**，只翻外围句子 |

## 三、专有名词清单（确认后不改）

- 模式名：`Car Jack City`、`Team Car Jack City`、`All for One`、`Turf War`、`Deal Breaker`、`Hangman's Noose`、`Bomb da Base II`、`Cops 'n Crooks`、`Race`、`GTA Race`、`Deathmatch`、`Team Deathmatch`、`Mafiya Work`、`Team Mafiya Work`、`Free Mode`、`Cops 'n Crooks` 等
- 队名：`Team One` ~ `Team Four` 等
- 电台名：`ZiT!`、`The Beat`、`Electro-Choc`、`Jazz Nation Radio`、`Liberty Rock Radio`、`Radio Broker`、`San Juan Sounds`、`Tuff Gong`、`Vladivostok FM`、`WKTT`、`PLR`、`Integrity 2.0`、`Vice City FM`、`Self-Actualization FM` 等
- 品牌/地点：`Liberty City`、`Algonquin`、`Bohan`、`Broker`、`Dukes`、`Alderney`、`Roman`、`Niko` 等人名地名，按系列惯例音译，不意译

## 四、书写要求

1. 保留原文里的格式控制符，一个不能丢：`~n~` `~r~` `~g~` `~b~` `~y~` `~p~` `~s~` `~a~` `~m~` `~z~` 等。
2. 每行文本长度尽量不超过原文的 120%，避免界面溢出。
3. 不加书名号、引号以外的任何标点；原文没有的句末句号不要补。
4. 数字、金额、时间格式照原样（`$5000` 不改成 `$5,000`）。
5. 同一术语全书统一，出现分歧以本文件第三节为准。

## 四点半、短词/碎片词怎么定（方法论）

遇到 `WEB STOP`、`POSITION`、`2 Door` 这种单看英文吃不准的碎片词，**先查同一 crc 的德文/法文条目**（语料里 `german` / `french` 两列就是官方译本），用官方二语的用词反推语义，比猜原文可靠。

已实测的样例：

| crc | English | German | French | 结论 |
|---|---|---|---|---|
| `068E072C` | WEB STOP | `WEB-STOPP` | `WEB STOP` | 手机浏览器「停止加载」按钮，**不是**「网络断开」 |
| `01166164` | POSITION | `PLATZ` | `POSITION` | 比赛名次，译「名次」而非「位置」 |
| `00292978` | PREV TRACK | `VORHERIGER TRACK` | `PISTE PREC.` | 「上一曲」，确认无误 |

德法两版也保留原词（如 `WEB STOP` 法文照抄）时，说明它是品牌/控件专名倾向，可在 `note` 里标 `待定`，留到真机界面确认。

## 五、来源与去向

- 队列：`gta4-chs\data\translate_queue.tsv`（列：chapter / table / crc / kind / english）
- 译文：`gta4-chs\data\zh_<chapter>_<批次>.tsv`（列：crc / zh）
- 合并后回写 `gta4-chs\build\src_*.tsv`，再重新打包三章并跑 `gxt_verify_engine.py` 校验。
