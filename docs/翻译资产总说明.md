## 三、专名层（易维护设计）

- **`names_dict.tsv`**（约 120 条）：译名的唯一真相源，列 `english zh category note`。改一个词条，同文的所有键位一起生效。
- **`names_policy.tsv`**（472 条）：键位分桶，列 `chapter table crc english bucket category zh`；`bucket` ∈ `zh`（译）/`keep`（保留英文）/`dev`（开发残留不处理）。当前 zh 374 / keep 67 / dev 31。
- **`zh_base_names.tsv`(259) / `zh_TLAD_names.tsv`(62) / `zh_TBoGT_names.tsv`(53)**：由前两者自动生成，共 374 个键位。
- 生成器：`C:\Game\_tools\build_names_shards.py`；按词典刷新口径：`refine_policy_by_dict.py`。
- 一键开关：`C:\Game\_tools\names_toggle.py`

### 玩家可见文本的开关用法

```
python -X utf8 C:\Game\_tools\names_toggle.py --list
python -X utf8 C:\Game\_tools\names_toggle.py --category 店名 --mode keep   # 店名类回退英文
python -X utf8 C:\Game\_tools\names_toggle.py --category 店名 --mode zh     # 恢复中文
python -X utf8 C:\Game\_tools\names_toggle.py --crc 25092ED5 --mode keep    # 单条回退
python -X utf8 C:\Game\_tools\names_toggle.py --all keep                    # 全回退英文
```

`--category` 用**子串匹配**，类别名如 `店名`、`赛道`、`街道`、`节目`、`电台`、`署名`、`人名`、`昵称`、`帮派`、`任务`、`开发`。

回退后必须按第五节重新打包，否则 gxt 不更新。

关于"中文双字节导致长短/乱码"：GXT 按 UTF-16LE 存储，长度以字符计而非字节，所以**不会因为双字节截断**；真实风险是**显示宽度**——同样字符数下中文占两倍像素，故有 44 条单行超宽、34 条整体偏长被标出（多为上游原文本身就长）。这些是观感问题不是崩溃问题。
