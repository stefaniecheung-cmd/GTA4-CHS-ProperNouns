## 主补丁修复说明

本包附带的 `GTA4.CHS.asi` 在民间上游二进制基础上做了 **1 处定点修复**（仅此 1 字节，不改 `GTAIV.exe`，不含破解）：

- **问题**：链接矩形修复 hook 的安装处，特征码扫描返回的已是运行时绝对地址，原实现又经 `aslr_ptr` 无条件叠加模块偏置（`0x70000`），导致 `call` 写入位置整体偏移、覆盖原指令，触发 `0xC0000005` 写访问违例（崩点 RVA `0x249B5F`）。
- **二进制修法**：文件偏移 `0x08381` 单字节 `03 → 8B`（`add ecx,esi` → `mov ecx,esi`，地址原样使用）。
- **源码修复**：`gta_html_link.cpp` 去掉 `aslr_ptr`、改用 `raw_ptr`（1 文件 +4/−3），已提交上游 PR QCJW/GTA4.CHS#1，待合入。
- **修复版指纹**：269,312 B；MD5 `42572e279905147bdea816ad15a7e3d5`；SHA-256 `2eb58176cd47d12c1f57dd6f8ceca675416f4fad995066224d5872a8b757f6ac`。
- 完整根因、排查过程与未决边界见 `docs/GTA4汉化补丁与FusionFix冲突-修复全程摘要-20261113.md`。

## 翻译与润色原则

1. **语义优先、整句成译**：以完整语境和整句含义为准，不逐词硬译；对白按口语中译，称呼、语气贴合人物身份与场景；语序可按中文习惯重组，但不改变原意。
2. **多语对照校勘**：以英文为主本，对照官方德文、法文译本反推语义，纠正错译、补回漏译；德法两版也保留原词时，判为品牌 / 控件专名倾向，标注待定留待真机确认。
3. **专有名词分层**：人名、地名、昵称、任务赛道名按系列惯例音译；界面菜单、纯多人独占内容、制作名单、真实人物与品牌名不译；需玩家照抄键入的姓名字段保留英文，关键提示句中英双语。
4. **格式与控制符守恒**：`~n~` `~r~` `~g~` `~b~` `~y~` `~p~` `~s~` `~a~` `~m~` `~z~` 等控制码随原文逐字保留，不改配色、不串位；数字、金额、时间格式照原样；译文长度尽量不超过原文 120%，避免界面溢出。
5. **术语统一与缺字避让**：同一术语全书一致，分歧以术语表为准；缺字经改译避开，不硬塞未入字表的生僻字。
6. **质量闸**：三章 gxt 条目 0 缺 0 多；独有键核查通过；控制码守恒；回环打包 0 不一致。

## 安装（摘要）

1. 把压缩包 **解压到独立文件夹**，Windows 双击 `安装.bat`；SteamOS/Proton 在终端跑 `bash install.sh`（自动定位 Steam 库目录，不必放进游戏目录）。
2. 卸载：Windows 双击 `卸载.bat`；Linux 跑 `bash uninstall.sh`，还原到原版英文状态。
3. 装过其它旧汉化时，先跑清理脚本（Windows `清理旧汉化.bat` / Linux `bash cleanup_old_zh.sh`）隔离残留。

详见 `使用说明（必读）.txt`、`更新日志.txt`、`声明.txt`、`有意保留英文清单.tsv`。
