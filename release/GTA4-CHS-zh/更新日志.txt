v2.1 修订（2026-11-13，主补丁闪退定点修复 + 文档口径补全）
  - 主补丁 GTA4.CHS.asi 做 1 处定点修复：链接矩形修复 hook 安装处，特征码
    扫描返回的已是运行时绝对地址，原实现又经 aslr_ptr 无条件叠加模块偏置
    （0x70000），call 写入位置整体偏移、覆盖原指令，触发 0xC0000005 写访问
    违例（崩点 RVA 0x249B5F）。
  - 二进制等效修法：文件偏移 0x08381 单字节 03 → 8B（add ecx,esi →
    mov ecx,esi，地址原样使用）；逐字节 diff 仅此 1 字节，不改 GTAIV.exe。
  - 源码修复（gta_html_link.cpp 去掉 aslr_ptr、改用 raw_ptr，1 文件 +4/−3）
    已提交上游 PR QCJW/GTA4.CHS#1，待合入。
  - 修复版指纹：269,312 B；MD5 42572e279905147bdea816ad15a7e3d5；
    SHA-256 2eb58176cd47d12c1f57dd6f8ceca675416f4fad995066224d5872a8b757f6ac。
  - 未决边界（如实标注）：闪退修复为静态闭环 + 1 字节补丁，尚未长时间真机
    长跑复测；暂停菜单 ? 墙 / 挂起属另一条文本路径，当前以 FusionFix
    ExtraInfo=0 规避，中文包侧三项源码改进尚未编译验证。详见仓库 docs 摘要。
  - 文档补全翻译与润色原则（语义语境、英法德对照校勘、控制符守恒等），
    包内说明、仓库 notes、Release 正文与门面 README 四处一致。
