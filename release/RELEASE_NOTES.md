# GTA4 三章简中汉化包 v2.0（整合包）

在民间简中补丁 `GTA4.CHS.asi` 基础上，完成三章译文字典定稿、中文字库扩容与地图区名修复的非官方整合包。**本包自带汉化补丁本体，解压安装即可，无需另装原补丁。** 覆盖本体 / 失落与诅咒 (TLAD) / 夜生活之曲 (TBoGT) 三章。免费发布，仅供交流学习，禁止任何商业用途；不含破解、不提供游戏本体。

## 一、来龙去脉

GTA4 官方未提供简体中文。民间简中补丁 `GTA4.CHS.asi` 由**无名汉化组于 2016 年底立项**，2019 年停工后由 **GTA4 贴吧吧友接棒续作三年**完工（2024-09-13 版）。



* **v1.0（2026-09，"补丁的补丁"）**：在该民间补丁之上，补完其刻意保留英文的人名、地名、车名与整句漏译，字库扩至 3,580 字，并附 `mapfix.asi` 修复暂停地图区名乱码。该版不含原补丁本体，玩家必须先另装 `GTA4.CHS.asi` 才能使用。

* **v2.0（本版，整合包）**：在 v1.0 成果之上做三章译文定稿与字库再扩容，并把主补丁本体一并打包，形成**解压即装**的完整汉化包；我方只替换译文字典、字符表与字库图集，主补丁二进制未做改动。

### 3. 质量闸



* 三章 gxt 条目 **0 缺 0 多**；独有键核查通过；回环打包 0 不一致。

### 4. 沿用的既有修复



* `mapfix.asi`：修复暂停地图区名因内部码 −0x20 偏移导致的逐字乱码（75 条区名真值，入口精确匹配、不绘制、不写游戏内存）。

## 四、安装与卸载

**安装**



1. 把 zip 解压到一个**独立文件夹**（不要解压进游戏目录）。

2. 确认游戏与 Steam 未运行，双击 `安装.bat`；自动定位游戏本体（相对位置 → Rockstar 注册表 → Steam 注册表与库列表），无需把文件夹放进游戏目录。

3. 看到「全部文件安装成功」后启动游戏。

**卸载**

双击 `卸载.bat`：还原 update 目录的三章字库图集与译文字典为原版基底，删除主补丁、`GTA4.CHS` 数据文件夹与 `mapfix.asi`，回到原版英文状态。请勿删除包内 `_ORIGINAL_*` 文件。
