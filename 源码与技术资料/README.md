## mapfix.asi 是什么

暂停地图上区名显示乱码（如"兰塞特"错位成"?线垮"）的根因与修法：

- **根因**：暂停地图的区名标签串到达游戏字体函数 `CFont::ProcessString` 时，每个字已被上游多减了 0x20（字体"内部码 = 码点 −0x20"的约定被多应用一次）→ 按错误码点查字库 → 逐字错位 / `?`。`procdiag` 实机采集 49,489 条实证：52 个乱码串 +0x20 后 52/52 还原成正确的 74 区名。
- **修法**：mapfix 挂钩 `ProcessString` 入口（6 字节、选无重定位条目的首指令，ASLR 免疫）。进入时读字符串，**当且仅当它精确等于"某个区名每字 −0x20"**时，把字符串指针换成 DLL 内置的正确区名常量（`zone_table.h`，由脚本从成品 gxt 自动生成），其余调用原样透传。
- **安全性**：不绘制、不写游戏内存、修正串指向永久常量（无生命周期问题）、真值永不匹配 −0x20 形态（防递归）。离线仿真对全部实测日志验证：乱码串全命中、其它串零误伤。

细节与更多原理见 `技术原理.md`。

## 重新编译 mapfix.asi

1. 安装 Visual Studio 2022（含 C++ x86 工具链）。
2. 把本文件夹 `mapfix/` 里的 `mapfix.cpp`、`zone_table.h`、`build_mapfix.bat` 复制到一个**纯英文路径**目录（MSVC 在中文路径下编译异常）。
3. 双击 `build_mapfix.bat`（核心命令：`cl /nologo /O2 /MT /LD mapfix.cpp /Fe:mapfix.asi /link /MACHINE:X86`）。看到 `CL_OK` 即成功，产物为 32 位 DLL、改扩展名为 `.asi`。
4. 如果区名译名有变更：先跑 `mapfix/gen_zone_table_v7.js` 重新生成 `zone_table.h`，再执行第 2–3 步（脚本内路径常量为工程原路径，按你的目录调整即可；仓库根 `update/common/text/american.gxt` 即成品字典）。

## 复刻须知

- 脚本运行环境：Node.js（本项目用 v24）；`.js` 里的 `E:/SteamLibrary/...` 为工程原路径，复刻时按需修改。
- `mapfix.cpp` / `procdiag.cpp` 注释为纯 ASCII：MSVC 会把 UTF-8 中文注释按 GBK 解码而吞掉下一行。
- `.asi` 即 32 位 DLL（仅改扩展名），由游戏目录的 ASI Loader 在启动时加载；加载按文件名字母序，mapfix 会等 `GTA4.CHS.asi` 就绪后再挂钩。
- 两条硬约束（详见 `技术原理.md` 第三节）：译文用字必须 ∈ `char_table.dat`（否则显示 `?`）；该表必须严格升序且"格号 == 数组索引"（二分查找），**新字不能追加末尾**，须插排序位并整张重编字模图。
